# TheQueueMBoy queuing system 

A simple system built for a school project to establish efficiency in an organization or offices. 

## Features

### Client Side:
 - Get queue number
 - View line position
 - View waiting list
 - Get estimated waiting time

### Admin Side:
 - Mark queues as complete
 - View waiting list
 - View line position

## Getting Started
